# WNV season length / emergence analysis

Code to reproduce the gridMET season-length model comparison tables, the M12
emergence figure, the GAM (human incidence / mosquito pool prevalence)
figures, and the temperature-threshold sensitivity figure.

## Setup

Run everything from this directory (the project root) — all scripts use
paths relative to it, e.g. `data/...`, `results/...`. Open this folder in
RStudio (or `setwd()` into it once yourself) before sourcing any script.

Requires `INLA` (not on CRAN):

```r
install.packages("INLA", repos = c(INLA = "https://inla.r-inla-download.org/R/stable"), dep = TRUE)
```

Also needed: `tidyverse`, `data.table`, `spdep`, `sf`, `tigris`, `rsoi`,
`patchwork`, `mgcv`, `ggrepel`, `readxl`, `forcats`. `tigris` (county
shapefiles) and `rsoi` (ONI/ENSO index) both pull from the network on first
run and cache locally after that.

## Run order

Scripts are numbered in dependency order — each one only needs outputs from
earlier-numbered scripts. INLA model fitting (02-05, 07, 10) is slow;
`05_gridmet_m12_emergence_figure.R` and `07_gam_season_length_models.R`
re-load cached `.rds` models from `data/` if they already exist instead of
refitting.

| # | Script | Produces |
|---|--------|----------|
| 01 | `gridmet_season_metrics.R` | `data/wnv_transmission_season_gridMET_1980_2024.csv` — first/last day of temperature suitability and season length per county-year, 1980-2024 |
| 02 | `gridmet_season_length_inla_models.R` | `results/tables/gridMET_season_length_model_comparison.csv` (28-model comparison) + cached `data/gridMET_m*.rds`, incl. the M12 model |
| 03 | `gridmet_first_day_inla_models.R` | `results/tables/gridMET_first_day_model_comparison.csv` + cached `.rds` models |
| 04 | `gridmet_last_day_inla_models.R` | `results/tables/gridMET_last_day_model_comparison.csv` + cached `.rds` models |
| 05 | `gridmet_m12_emergence_figure.R` | `results/figures/gridMET_m12_emergence_threepanel.png` |
| 06 | `build_case_counts.R` | `data/cases_by_county_year.csv` — human WNV case counts, 0-padded to every county × year 1999-2024 |
| 07 | `gam_season_length_models.R` | `results/figures/gam_season_length_panel.png`, `results/figures/gam_loo_fourpanel.png` + exports `data/plot_inputs/*.csv` for script 08 |
| 08 | `gam_figures_from_cache.R` | Optional — rebuilds the same two figures from `data/plot_inputs/*.csv` only, without INLA/GAM refitting or the private case/prevalence spreadsheets. Useful for aesthetic tweaks. |
| 09 | `gridmet_sensitivity_season_metrics.R` | `data/wnv_transmission_season_gridMET_sensitivity.csv` — season metrics under alternate temperature-threshold scenarios |
| 10 | `gridmet_m12_sensitivity_threshold.R` | `results/figures/sensitivity_trajectory_ref1999.png` |

`results/` already contains the versions of these tables and figures as
published, generated from the original raw data — for reference and in case
of any non-determinism in the ONI download or MCMC-free INLA fit.

## Data

`data/` contains the raw inputs each script starts from:

- `county_gridmet_data/NY_county_gridMET_TMEAN.csv`, `NY_county_gridMET_spei90d.csv` — daily county-level gridMET temperature and 90-day SPEI, 1980-2024
- `NY_county_mean_elevation.csv`, `NY_county_pop_wt_elevation.csv` — county elevation (unweighted and population-weighted)
- `NY_county_koppen_zones.csv` — Köppen climate classification per county
- `NYS Human WNV cases.xlsx` — annual human case counts per county
- `WNV prevalence master spreadsheet.xlsx` — mosquito pool WNV prevalence
- `ny_counties_ghsl_population_annual_1999_2024.csv` — annual county population

Everything else in `data/` (season metrics, `cases_by_county_year.csv`,
cached `.rds` models, `plot_inputs/`) is generated by the numbered scripts.
